## The model grid on a map

The model files do not say where the grid is. ADWR's GIS files do have this information, but we know the "projections" for both datasets (more on that next semester). To translate between the two coordinate systems you will use the following information:

| Property | Value |
|---|---|
| Coordinate system | NAD83 / UTM zone 12N (EPSG:26912), in metres |
| Rotation | none: rows run west to east, columns north to south |
| Cell size | 2,640 ft = 804.672 m, square |
| North-west outside corner of row 0, column 0 | x = 298038.855 m, y = 3755018.614 m |
| Grid size | 196 rows, 222 columns, 3 layers |

Rows are numbered from the north edge downward and columns from the west edge
eastward, both starting at 0, the same as FloPy. To convert latitude and
longitude to UTM coordinates, use `pyproj` (already installed):

```python
from pyproj import Transformer

to_utm = Transformer.from_crs("EPSG:4269", "EPSG:26912", always_xy=True)
x_m, y_m = to_utm.transform(longitude, latitude)    # longitude first
```

`transform` accepts single numbers or whole DataFrame columns. From there, use information about the model grid (e.g. cell size and corner locations) to map between the `x_m` and model grid location.
