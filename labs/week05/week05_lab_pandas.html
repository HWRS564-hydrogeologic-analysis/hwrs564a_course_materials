Week 5 Lab — Pandas and time series

How to use this notebook

Work from top to bottom. Read the prose, run each example, and complete every YOUR TURN cell. The checks verify structure and selected values; they do not replace interpreting the table and figures.

By the end, restart the kernel and run all cells. The completed solution should take about 2.5–3 hours in class.

Learning objectives

By the end of this lab, you should be able to:

  • read and inspect a labelled table;
  • select and filter rows without silently losing track of missing values;
  • parse dates and use a DatetimeIndex;
  • distinguish monthly resampling from a monthly climatology;
  • compute water-year and rolling summaries; and
  • group and reshape irregular groundwater observations.

Part 2 — Select columns and filter rows

One name selects a Series; a list of names selects a DataFrame.

depth = wells["well_depth_ft"]
location_and_depth = wells[["site_no", "latitude", "longitude", "well_depth_ft"]]
print(type(depth).__name__, type(location_and_depth).__name__)

A filter is a boolean Series aligned with the table’s index. Inspect missing depths before applying a depth comparison: NaN fails every comparison and the row otherwise disappears without a warning.
