Week 9 Lab — Linear regression clinic

HWRS 564a · Fall 2026

Today is a full-period working session. You will derive, fit, diagnose, validate, and interpret one simple linear model using a 63-year groundwater record. The purpose is not to collect outputs from a function. It is to decide which statements those outputs support.

Learning objectives

By the end of the lab you can:

  1. reproduce the OLS slope and intercept from centred sums;
  2. explain how centring changes the intercept but not the slope;
  3. calculate RSS, TSS, \(R^2\), residual variance, slope standard error, and a confidence interval;
  4. diagnose nonlinearity, unequal variance, non-normality, and serial correlation;
  5. compare interpolation and forecasting validation; and
  6. separate descriptive, inferential, predictive, and causal claims.

Run cells in order. Every # YOUR TURN cell has a following # CHECK cell. Before leaving, restart the kernel and run all cells.

Part 1 — Prepare a predictor with interpretable units

We will model depth to water as a linear function of elapsed time. Because depth is measured downward, a positive slope means the water table becomes deeper: a decline in hydraulic head.

from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats

ROOT = next(
    p for p in [Path.cwd(), *Path.cwd().parents]
    if (p / "pyproject.toml").exists()
)
DATA = ROOT / "data"

levels = pd.read_csv(
    DATA / "tucson_water_levels.csv",
    dtype={"site_no": str},
    parse_dates=["date"],
)

one = (
    levels.loc[levels["site_no"] == "320824110593001"]
    .sort_values("date")
    .dropna(subset=["date", "depth_to_water_ft"])
    .copy()
)
one["years_elapsed"] = (one["date"] - one["date"].min()).dt.days / 365.25

print(f"{len(one)} measurements from {one['date'].min():%Y} to {one['date'].max():%Y}")
print(one[["date", "years_elapsed", "depth_to_water_ft"]].head())

Common pitfall: dropping missing values from \(x\) and \(y\) separately can destroy their row-by-row pairing. Drop incomplete rows from both required columns in one operation, as above.

Part 2 — Centre the predictor to make the intercept useful

Changing the origin of \(x\) should not change the slope. It changes which date the intercept describes.

Common pitfall: interpreting an intercept at \(x=0\) when zero is far outside the data or has no physical meaning. Centre the predictor at a meaningful date or condition. This changes the intercept and its uncertainty, not the fitted line.

Interpretation:

  • Decade-long residual structure challenges a single linear mean.
  • Lag-1 correlation of 0.986 strongly rejects independence.
  • Residual spread is about 1.8 times larger in the upper fitted range, challenging constant variance.
  • The Q–Q plot checks distributional shape, but normal-looking residuals would not repair dependence or nonlinearity.

The OLS line remains a descriptive line. The ordinary standard error and confidence interval are much harder to defend.

Common pitfalls:

  • Test \(R^2\) can be negative. It means predictions are worse than using the test-set mean as a baseline.
  • Random splitting is not inherently wrong; it answers an interpolation question. It is wrong when presented as evidence of forecasting ability.
  • MAE and RMSE retain the response units. RMSE reacts more strongly to large misses.

Now write a four-sentence conclusion in your own words:

  1. Descriptive: state the fitted rate, direction, units, site, and period.
  2. Inferential: state that the narrow ordinary interval is conditional on assumptions that the residual diagnostics challenge.
  3. Predictive: state what the chronological validation shows.
  4. Causal: name at least one plausible process that elapsed time does not itself identify, such as pumping or recharge.

Avoid these phrases:

  • “\(R^2=0.90\), so the model is 90% accurate.”
  • “The p-value proves groundwater decline.”
  • “Time caused the water table to fall.”
  • “The confidence interval contains 95% of future observations.”

Before you leave

  1. Restart the kernel and run all cells.
  2. Resolve every failed check.
  3. Save the notebook.
  4. Confirm that your written interpretation separates descriptive, inferential, predictive, and causal statements.

If you get stuck

  • linregress returns nan: drop incomplete \(x\)–\(y\) rows together.
  • Your slope has units of ft/day: convert the datetime difference to years.
  • Your residuals have the opposite sign: use measured minus predicted.
  • Your standard error is close but not equal: residual variance uses \(n-2\).
  • Your random-split values change: use random_state=564.
  • Expected 2D array: scikit-learn requires X shaped (rows, predictors); use double brackets around the predictor column.
