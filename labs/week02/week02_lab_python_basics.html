Week 2 Lab: Python basics

HWRS 564a · Fall 2026

This notebook is the hands-on companion to the Week 2 slides. Work through it in class; finish anything you don’t get to before Thursday.

How to use this notebook

Run each cell with Shift+Enter. Cells marked # YOUR TURN have something for you to write. Cells marked # CHECK verify your answer — if they run without complaint, you’re right.

Before you submit anything all semester: Kernel → Restart Kernel and Run All Cells. A notebook that only works when run out of order is not finished.

Learning objectives

By the end of this notebook you should be able to:

  1. Run code in a notebook and predict what the kernel is holding
  2. Assign variables and check their types
  3. Convert between types, and recognize a TypeError when you cause one
  4. Index and slice a list using zero-based, half-open conventions
  5. Choose between a list, a tuple, and a dictionary
  6. Import a module and call a function from it

A conversion that surprises people

print(int(45.7))          # truncates toward zero — does NOT round
print(int(float("45.7")))  # works: str -> float -> int
print(round(45.7))         # this is what rounds

# int("45.7") raises ValueError. Try it if you like.

Strings: text values

A string is text: a sequence of characters enclosed in single or double quotes. Well IDs, site names, and values read from a text file are strings. Python keeps the quotes out of the value itself.

Strings can be indexed one character at a time. Python starts counting at zero, and negative indices count backward from the end:

well_id = "A-14"
basin = 'Santa Cruz Basin'

print(well_id[0])   # A
print(well_id[-1])  # 4

Strings can be combined by adding them, this is known as concatenation.

well_id + basin

To combine text with variable values, use an f-string. Put the variable name inside braces; Python substitutes its value when the line runs:

The result is still a string. If a string contains a number such as "45.7", convert it with float() before doing arithmetic.

message = f"Well {well_id} is in the {basin}."
print(message)

Floating point

Floats are binary approximations of decimal numbers.

print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)

Never compare floats with ==. Compare the magnitude of the difference against a tolerance:

\[|a - b| < \epsilon\]

You’ll use this test to decide when an iterative solver has converged.

tolerance = 1e-9
print(abs((0.1 + 0.2) - 0.3) < tolerance)

Lists, indexing, slicing

A year of monthly water-level measurements, January first.

monthly_head = [
    415.2, 414.8, 414.1, 413.2, 412.0, 410.6,
    409.1, 411.7, 413.9, 414.6, 415.0, 415.3,
]

print(f"number of measurements: {len(monthly_head)}")
print(f"January (index 0):      {monthly_head[0]}")
print(f"December (index -1):    {monthly_head[-1]}")
print(f"lowest level:           {min(monthly_head)}")

Slices are half-open: [start:stop] includes start and excludes stop. So stop - start is always the number of elements you get.

print(f"first quarter:  {monthly_head[0:3]}")
print(f"same thing:     {monthly_head[:3]}")
print(f"from July on:   {monthly_head[6:]}")
print(f"last two:       {monthly_head[-2:]}")

Tuples and dictionaries

A tuple is a fixed collection that represents one thing. A dictionary maps names to values.

grid_shape = (3, 40, 60)   # layers, rows, columns — a MODFLOW grid
n_layers, n_rows, n_cols = grid_shape   # unpacking
print(f"{n_layers} layers, {n_rows} rows, {n_cols} columns")
print(f"total cells: {n_layers * n_rows * n_cols}")

# grid_shape[0] = 5 would raise TypeError — tuples are immutable
aquifer = {
    "name": "Santa Cruz",
    "conductivity": 12.4,
    "porosity": 0.28,
    "confined": False,
}

print(aquifer["conductivity"])
print(aquifer.get("storativity", "not measured"))   # no KeyError
print(f"keys: {list(aquifer.keys())}")

YOUR TURN 5 - Darcy’s law

For one-dimensional flow through a confined aquifer:

\[Q = -KA\frac{dh}{dl}\]

Here \(A\) is the cross-sectional area perpendicular to flow. The specific discharge is the flow per unit area, \(q = Q/A\). Darcy’s law gives \(q = -K\,dh/dl\); because we are reporting the magnitude of flow downhill, use \(q = K \times \text{gradient}\). Then calculate the volumetric flow with \(Q = qA\).

  • gradient: the hydraulic gradient between the wells

Sanity-check your own answer

Q came out around 2700 m³/d. Is that a lot?

Convert it to something you have intuition for, litres per second, or acre-feet per year, and decide whether the number is plausible for a basin this size. Getting into this habit now will save you from submitting a MODFLOW model with a 10⁶ m³/d error at the end of the semester.
